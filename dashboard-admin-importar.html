ADMIN

Importación masiva de personas donantes

Subí el padrón de personas donantes en un archivo .csv de hasta 10.000 filas o más: identificamos a quienes ya están registradas, actualizamos sus datos y damos de alta con acceso automático a las nuevas.

Cómo funciona la importación

Cada fila representa una persona donante humana o jurídica. El sistema toma el email como dato principal para ubicarla: si ya existe, actualiza su información; si no existe, crea el usuario y le envía sus accesos automáticamente.

Archivo de prueba: 20.000 filas
1. SUBIR CSV

Importar archivo completo

Se procesa el lote completo aunque tenga más de 10.000 filas.

2. IDENTIFICAR

Buscar por email

El correo permite ubicar a la persona donante para decidir si se actualiza o se crea.

3. ACTUALIZAR / CREAR

Mantener padrón al día

Si ya existe, se actualizan datos. Si no existe, se genera un nuevo usuario.

4. ENVIAR ACCESOS

Credenciales automáticas

Las personas nuevas reciben correo de bienvenida con sus datos de acceso.

Formato esperado del archivo CSV

Cada línea debe incluir los datos mínimos para poder identificar y contactar a la persona donante.

Si el email ya existe

Se actualiza la ficha de la persona donante con los datos del CSV.

Si el email no existe

Se crea el usuario y se envían las credenciales de acceso automáticamente.

Resultado esperado

El padrón queda listo y las personas nuevas reciben sus accesos para ingresar a la plataforma.

ⓘ

Importante: con estos datos debe ser posible ubicar a la persona donante en el sistema. Si no está registrada, el sistema crea su usuario y le envía un correo con las credenciales de acceso. Se recomienda cargar el archivo en formato UTF-8.
